# nBPI Calculator

beatmania IIDXの実力指標「nBPI」を算出するWebアプリケーションです。
BPIManagerからエクスポートしたCSVファイルを読み込ませるだけで、瞬時にnBPIを計算できます。

## 概要

もともとStreamlitアプリとして開発されていましたが、現在はブラウザ上で動作する**クライアントサイドWebアプリ**（HTML/CSS/JS）として生まれ変わりました。
これにより、サーバーへのアップロード不要で、爆速かつセキュアに動作します。

## 使い方

1.  Webアプリを開きます。
2.  **BPIManager** の「設定 > その他 > エクスポート」から保存したCSVファイルをアップロードします。
3.  難易度レベルや対象曲数を調整すると、リアルタイムにnBPI計算されます。
4.  結果のCSVダウンロードも可能です。

## プロジェクト構成

*   `docs/`: Webアプリケーションのソースコード (HTML/CSS/JS)。**現在はこちらがメインです。**
*   `app.py`: 旧Streamlit版のコード（アーカイブ用）。
